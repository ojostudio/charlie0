Configure o Firebase para ativar o painel

Este painel usa Firebase (Auth + Firestore + Storage). Para ligá-lo:

  1. Crie um projeto em console.firebase.google.com.
  2. Ative Authentication → E-mail/senha, crie um Firestore e o Storage.
  3. Cole as chaves do app em js/firebase-config.js.
  4. Publique as regras de segurança do Firestore e do Storage.
  5. Crie o primeiro usuário admin direto no console do Firebase (Authentication → Add user), depois crie o documento correspondente na coleção users do Firestore (doc ID = UID do usuário) com os campos name, email, role: "admin".
